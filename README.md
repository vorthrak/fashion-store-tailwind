# 👕 FASHION STORE

Website toko fashion sederhana berbasis HTML dan Tailwind CSS. Menampilkan produk fashion premium seperti topi, kaos, dan jaket varsity, lengkap dengan tombol pembelian langsung ke WhatsApp.

## 🔧 Fitur

- Desain responsif menggunakan Tailwind CSS
- Tampilan produk menarik (gambar, nama, deskripsi, harga)
- Tombol "Beli Sekarang" langsung terhubung ke WhatsApp
- Navigasi yang simpel dan jelas
- Cocok untuk kebutuhan toko kecil atau katalog online pribadi
